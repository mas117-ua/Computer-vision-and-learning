## 🎯 Overview
This project implements various neural network architectures to classify images from the CIFAR-10 dataset. It explores both Multi-Layer Perceptrons (MLPs) and Convolutional Neural Networks (CNNs) using the Keras framework, with a focus on understanding and optimizing different model parameters.

## ✨ Features
- 🧠 Implementation of MLPs and CNNs for image classification
- 🎛️ Comprehensive parameter optimization studies
- 📊 Custom dataset creation and validation
- 📈 Visualization of training metrics and results
- 📋 Multiple evaluation metrics including confusion matrices
